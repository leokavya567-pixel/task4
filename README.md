 # Task 4 - Dashboard Design

## Project Overview

This project focuses on designing an interactive business dashboard using Power BI. The dashboard helps stakeholders analyze sales performance, profitability, customer trends, and regional performance through interactive visualizations and filters.

## Objective

To create an interactive dashboard that provides meaningful business insights and supports data-driven decision-making.

## Tool Used

- Microsoft Power BI

## Dataset

Sample Superstore Dataset

### Key Fields Used

- Order Date
- Sales
- Profit
- Quantity
- Customer Name
- Category
- Sub-Category
- State
- Region

## Dashboard Features

### KPI Cards

- Total Sales
- Total Profit
- Total Orders

### Visualizations

- Monthly Sales Trend
- Sales by Category
- Top 10 Customers
- Sales by State

### Interactive Slicers

- Region
- Category
- State
- Year

## Business Insights

1. Technology category generated the highest sales among all categories.
2. California was one of the top-performing states in terms of revenue.
3. A small group of customers contributed significantly to overall sales.
4. Sales performance varied across different regions.
5. Monthly sales trends helped identify periods of strong business performance.

## Outcome

This project demonstrates the use of Power BI to transform raw business data into interactive visualizations and actionable insights. The dashboard enables stakeholders to monitor key performance indicators, analyze trends, and make informed business decisions.
